# MCP Factory

An MCP server that creates other MCP servers. TypeScript.

## Structure

- `src/` — Source
- `dist/` — Compiled output (entry: `dist/index.js`)
- `servers/` — Generated MCP servers
- `docs/` — Documentation

## Commands

```bash
npm run build   # Compile TypeScript
npm start       # Run the factory server
```
